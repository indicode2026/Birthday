# 🎂 Birthday Website

A fun interactive birthday website made with HTML, CSS and JavaScript.

## Files
- `index.html` — main webpage
- `style.css` — design and animations
- `script.js` — buttons, messages and effects

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## GitHub Pages
1. Create a GitHub repository.
2. Upload these three files.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Then share the GitHub Pages link with your friend. 🎉
